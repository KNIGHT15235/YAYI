# YAYI 核心页面改版验证

项目：`D:\ldj\01\YAYI_0929`。本次仅调整前端页面、导航和展示交互。

## 页面结构

| 页面 | 路径 | 实现 |
| --- | --- | --- |
| 首页 | `/` | 独立科研工作台；研究入口、问题示例、最近真实记录、资源入口、六角色能力说明 |
| 深度研究 | `/chat` | 原“新的研究”更名；保留研究问题、附件、搜索范围、知识库选择；支持问题预填 |
| 研究详情 | `/chat/:id` | 继续使用原研究流程、报告、引用、文献、假设审核、图谱和图表 |
| 研究历史 | `/history` | 独立页面；真实记录、标题搜索、类型筛选、日期、分页、重命名、删除确认 |
| 知识库管理 | `/knowledge` | 保留上传、解析、检索和原文能力，修复窄屏；解析中不再显示虚构的固定 30% |
| 数据库探索 | `/database` | 接通现有表浏览、自然语言查询、SQL、结果表格及图表 |
| 科研资讯 | `/news` | 接通现有资讯；主题/类型筛选、原文、采集与研究问题预填 |
| 记忆库 | `/memory` | 保留原列表和语义检索，增加来源研究入口，修复窄屏卡片 |

登录页外观、登录表单和 YAYI 图标未改；直接登录成功后的默认落点由 `/chat` 改为 `/`，受保护页面登录仍返回原目标。品牌文字保持 YAYI 大写。
