## 实测发现及修复

1. DocMind 图像链接实际位于 Markdown 中，且带临时签名。现在仅将链接用于下载 PNG，规范化正文及公开资产中不保留签名链接。
2. DocMind `pageNum` 从 0 开始。现在保留原始 `page_index`，展示页码加 1；未返回页码时保持缺失。
3. 表格标题、图注不能算作独立表格或图片资产。现在区分实际对象与标题／图注。
4. 表格单元格文字实际位于嵌套 `layouts` 中。现在保留单元格文字及行列索引。
5. 每个片段定位曾重复携带整表单元格，现已去重并移除该重复内容。167 个片段的定位 JSON 从 8,992,956 字节降至 341,133 字节；完整表格仍保存在资产详情。知识库片段文本、ID 和向量没有因此变化。

修复复用了同一个已完成的 DocMind 任务结果，未再次提交付费解析任务。重建仅更新此演示论文，随后又以逐条一致性断言确认元数据补齐不改变片段文本和 ID。

## 明确的限制

- 10 个公式资产中，5 个返回可明确提取的编号，另 5 个保持为空。部分公式存在 OCR 转写误差，数学符号仍需回查原文。
- 本文档返回了表格行列索引，但没有精确的单元格像素框；已有坐标定位表格或版面块。
- 部分图号、表号位于独立标题块，尚未自动绑定到资产。可使用真实页码和资产链接回查。
- 图像资源按解析器识别区域提取，部分可能是多子图中的一个区域，并非整幅组合图。
