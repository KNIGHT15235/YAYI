# 调研模式切换验证

日期：2026-09-30。

## 实现范围

- 深度研究入口 `/chat` 默认选择“科研背景调研”，可切换“行业调研”；切换状态保存在当前页面 URL 的 `mode` 参数中，刷新仍保留该选择。
- 两种模式使用不同说明、输入提示、示例问题与工作流文案。行业模式可选择行业主题；示例和资讯仅填入输入框，不会自动开始研究。
- 新任务携带对应 `profile_id` 调用 `/research/stream`：科研为 `science`，行业为 `industry`。科研默认 60 篇，行业不携带文献数量阈值。
- 历史研究读取检查点中保存的配置；旧行业检查点继续使用行业模式。更改新任务模式不会覆盖历史模式。恢复研究仍使用空请求体，由后端读取原检查点；人工审核接口未改动。
- 研究任务未选择网络或本地知识库时会提示选择来源，避免静默进入普通对话。首次提交时不并行覆盖新会话消息，防止历史预载响应替换正在创建的研究消息。
- 初始问题按会话记录为已消费；在同一页面组件内从研究 A 切到研究 B 再回到 A 时，会重新读取历史，不重复提交旧问题或追加旧消息。
- 登录界面、YAYI 标志、六个 Agent 与模型配置均未调整。
