**最终状态：用户已完成两项设置，复测57/57通过。** PDF云解析、真实向量生成、中文知识库检索与长期记忆召回均已恢复。以下为初测问题及处理步骤的留档，不表示当前仍需再次充值或开通。最终结果见 [项目核对报告.md](项目核对报告.md)。

## 1. 百炼 text-embedding-v4：免费额度耗尽且开启仅免费模式

实测接口返回 HTTP 400，错误码 `AllocationQuota.FreeTierOnly`，提示免费额度已耗尽。它影响知识库文档向量化、查询向量生成、长期记忆向量化与语义召回。普通聊天和 Text2SQL 的模型调用已成功，不能把所有模型都认定为不可用。

操作步骤：

1. 登录创建 `backend/.env` 中 `DASHSCOPE_API_KEY` 的阿里云账号。无需把 Key 发给任何人。
2. 打开 [阿里云费用与成本](https://billing-cost.console.aliyun.com/)，查看账户可用余额。如果不足，点击“充值”或“充值汇款”，按页面填写金额并自行完成支付；已有足够余额时无需重复充值。
3. 打开 [阿里云百炼控制台](https://bailian.console.aliyun.com/)，选中该 API Key 对应地域/空间。当前项目调用 `dashscope.aliyuncs.com` 中国内地接口。
4. 进入“费用用量 → 免费额度”（部分界面放在“模型用量”内），搜索 **text-embedding-v4**，关闭它的“免费额度用完即停／仅使用免费额度”开关。只处理这个已经确认阻塞的模型即可。
5. 若开关不可操作，先检查实名认证及主账号/RAM权限。未实名认证用户可能被强制限制为仅免费模式。
6. 等待设置生效，再复测一次小文本向量生成。关闭开关后，后续调用超出免费额度的部分会按量计费。不要仅充值后就假设问题已恢复。

官方依据：[免费额度及开关说明](https://help.aliyun.com/zh/model-studio/new-free-quota)、[账单查询与充值说明](https://help.aliyun.com/zh/model-studio/bill-query-and-cost-management)。实际金额和支付方式以你账号页面为准，本次没有估算或承诺费用。

## 2. DocMind：账号未开通服务

一次小型合成 PDF 提交返回 HTTP 200，但业务错误为 **DocMindServiceNotOpen**，消息为 “You have not open the docMind service.”，没有任务 ID。这不是普通的代码语法错误，也没有证据表明是欠费。

操作步骤：

1. 登录项目 `DOCMIND_ACCESS_KEY_ID` 所属的阿里云账号。该账号未必与 DashScope Key 所属账号相同，需自行确认。
2. 打开 [DocMind 控制台](https://docmind.console.aliyun.com/doc-overview)，进入“服务管理与开通”或“服务管理列表”。
3. 找到“文档理解”，确认包含 **文档解析（大模型版）** 能力。本项目使用 `SubmitDocParserJobAdvance → QueryDocParserStatus → GetDocParserResult`。
4. 阅读界面显示的服务协议、免费额度和计费方式，自行确认开通。若页面提示实名认证或权限不足，按提示处理。
5. 开通后先复测一页合成 PDF。TXT/MD 已支持本地解析，但后续向量化仍依赖第1项的 Embedding 服务。

官方依据：[控制台开通指南](https://help.aliyun.com/zh/document-mind/getting-started/user-guide-for-the-document-mind-console)、[本项目使用的文档解析API](https://help.aliyun.com/zh/document-mind/developer-reference/document-parsing-large-model-version)。
