# 数据库探索与科研资讯演示操作

本说明适用于 `D:\ldj\01\YAYI_0929`，网页地址为 http://localhost:5199。沿用现有账号、登录界面、YAYI 图标及六 Agent 研究流程。

## 为什么之前没有内容

数据库探索读取已开放的结构化业务表。原来的表目录和自然语言查询只面向行业数据，研究历史中的论文没有自动成为 SQL 表。知识库上传的 PDF 也不会自动填充这些表。

科研资讯需要先采集再展示。原配置没有遥感科研主题，数据库中的资讯为空，自动采集又处于关闭状态，所以进入页面没有内容。

## 已配置的数据

数据库新增两个可查询的公开数据表，来源为正式展示历史对应的 `audit/demo-result.json`：

| 网页名称 | 数据表 | 内容 |
| --- | --- | --- |
| 科研文献 | `research_papers` | 120 篇 2020—2026 年光学遥感变化检测论文，保留题名、作者、年份、DOI、公开来源链接、证据层级等字段 |
| 文献方法标签 | `research_paper_methods` | 188 条方法标签记录，可按文献标识关联论文 |

该数据集编号为 `yayi-optical-cd-2020-2026-demo-v1`。年份数量依次为 14、18、18、18、18、17、17。方法标签按题名和摘要中的关键词匹配，一篇论文可以有多个标签。因此，188 是标签记录数，不是论文数；这些统计只反映本次纳入的语料，不代表领域年度发文总量或方法性能排名。

本次演示选择上述科研表。原有“行业统计数据、企业数据、政策数据”表当前仍为 0 条，需要另行导入对应的真实业务数据后才能用于行业数据演示。

来源元数据核验与内容结论核验是不同字段含义。原文没有给出的期刊等信息保留为空，不补写推测值。原研究历史和综述保持原内容。

科研资讯新增“遥感与地球观测”主题，优先读取 ESA 的 Earth Observation 和 EO4Society 官方订阅源，保存题名、短摘要与原文链接，不需要新增 API 密钥。页面支持主题与分类筛选、来源回查和作为研究线索，采集时自动去重；无法确定的发布日期显示为未知。

本次已保存并展示 **39 条有效科研资讯**，按实际发布日期从新到旧排列。明确的采购、招标公告不进入科研展示列表；已有此类记录仅隐藏、不删除。当前这批内容均属于“新闻与动态”，因此“研报”等分类显示 0 属于实际分类结果。

## 网页演示顺序

### 1. 数据库探索：从真实文献到统计图

1. 登录后，点击左侧“数据库探索”。
2. 在表列表选择“科研文献”，查看 120 条记录；可查看字段及分页数据，点击 DOI 或来源链接回查原文。
3. 在自然语言输入框依次试用下面的问题，提交后查看 SQL、结果表和图表。

```text
按年份统计文献数量，并绘制柱状图。
```

```text
比较不同方法标签的文献数量。
```

```text
列出2025年以来的文献标题、年份和DOI。
```

第一项应返回 7 个年份，第二项应返回 10 种标签，第三项应返回 34 篇论文。也可以直接点击页面提供的示例问题。切换到“文献方法标签”可以解释论文与多标签的关联关系。

数据库探索展示已接入、已发布的结构化数据，普通的自然语言提问不会创建新数据。查询接口仅开放业务表并执行只读 SQL，不开放账户、记忆或研究会话表。

### 2. 科研资讯：从外部动态进入研究

1. 点击左侧“科研资讯”，默认主题为“遥感与地球观测”。
2. 查看已收录的资讯，可按主题和分类筛选；通过原始来源链接核对完整内容。
3. 点击“采集资讯”获取新线索。结果会说明新增数量；重复采集没有新增时会明确提示。
4. 点击一条资讯的研究入口，将该线索带入“深度研究”。科研主题自动选择“科研背景调研”，行业主题选择“行业调研”；问题只是预填，可编辑后再发送。

“近 24 小时”按本系统收录时间统计，不表示这些文章都在今天发布。资讯可能涉及卫星任务、地球观测数据、算法或科研活动；它们用于发现研究线索，不能替代论文及其证据审核。

## 后续如何补充内容

**更新资讯**：直接在网页选择主题并点击“采集资讯”。科研主题优先用官方订阅源，不调用招投标采集接口。自动定时采集仍关闭，手动采集后的内容保存在数据库中，刷新页面仍可查看。

本次实测发现已有 Bocha 搜索接口返回 HTTP 403，因此科研资讯采用无需密钥的官方订阅源。原搜索配置作为备用保留；如果后续需要使用搜索采集或原行业资讯采集，需要检查该服务的账号授权、配额或网络限制。403 的具体原因尚未由服务商确认，不能仅凭状态码认定密钥失效。

**恢复这套文献演示数据**：当前已经导入，不需要重复运行。以后如果重新初始化 YAYI 数据库，可以在 WSL 的现有环境执行：

```bash
cd /mnt/d/ldj/01/YAYI_0929
# 先核对正式展示文件、文献数量和标签统计，不写入数据库
/home/ldj/anaconda3/envs/yayi_b/bin/python audit/configure_database_demo.py
# 核对通过后发布到 yayi_0929 数据库
/home/ldj/anaconda3/envs/yayi_b/bin/python audit/configure_database_demo.py --apply
```

导入脚本核对目标数据库和语料编号，以事务写入，并可重复执行。它只发布这套正式展示语料，不是任意 CSV 导入器，也不会自动同步后续所有研究历史。如果以后需要演示其他专题，应准备对应的真实结构化数据，再增加受控导入和表目录；上传论文全文仍使用“知识库管理”。
